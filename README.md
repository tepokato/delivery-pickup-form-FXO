# 📦 Delivery pickup form FXO

This web-based application streamlines the process of submitting package pickup or delivery requests at FedEx Office locations. Designed for internal staff use, the form allows employees to input essential information about the guest, package details, and request type, then generate a neatly formatted PDF for recordkeeping or operational coordination.

🔧 Features
Dual Mode Support: Select between Pickup or Delivery to dynamically reveal the corresponding fields.
PDF Export: Auto-generates a clean and printable summary in PDF format using jsPDF.
Location Management: Preloaded location options with support for custom entries via "Add New Location."
Form Controls: Reset button and input validation for a smooth user experience.
FedEx-Themed UI: Styled with the official FedEx brand palette for familiarity and clarity.
📝 Required Fields
Employee Name
Badge Number
At least one request type (Pickup or Delivery)
🚀 Getting Started
To use the form:

Open the delivery:pickup form-beta02.html file in any modern web browser.
Fill in all relevant details based on the package request.
Select the appropriate request type.
Click “Download as PDF” to generate the form summary.
🔐 Note on Payment Info
If credit card information is collected, the checkbox will be marked, and a note will indicate that this information is securely stored offline.
